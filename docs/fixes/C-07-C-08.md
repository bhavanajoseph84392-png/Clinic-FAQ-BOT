# C-07 / C-08: Mock Email Reports Success and Prints the Body

## What was wrong

- **C-07:** When no email provider was configured, `send_email` logged a mock message and returned `True`, so callers believed delivery succeeded even though nothing was sent.
- **C-08:** The same mock branches printed the recipient, subject, and full `html_body` to standard output, exposing patient-facing message content in console logs.

## Code evidence

Before the change, the Resend mock branch was at `app/emailer.py:24-27`:

```python
            if not settings.RESEND_API_KEY:
                logger.warning("RESEND_API_KEY is not set. Simulating email log.")
                print(f"[EMAIL MOCK - RESEND] To: {to_email} | Subject: {subject}\n{html_body}")
                return True
```

The SMTP mock branch was at `app/emailer.py:55-58`:

```python
            if not settings.SMTP_USER or not settings.SMTP_PASSWORD:
                logger.warning("SMTP credentials not configured. Simulating email log.")
                print(f"[EMAIL MOCK - SMTP] To: {to_email} | Subject: {subject}\n{html_body}")
                return True
```

The `print` calls at `app/emailer.py:26` and `app/emailer.py:57` caused C-08. The `return True` lines at `app/emailer.py:27` and `app/emailer.py:58` caused C-07.

## Caller review

| Caller | Handling of `False` |
| --- | --- |
| `app/jobs.py:112-114` | Raises `RuntimeError("Email delivery failed")`; the job is retried and eventually marked failed. Safe. |
| `app/pending.py:74-75` | Sets `email_status = "failed"` and returns `email_delivered = False`. Safe; it does not report delivery success. |

No caller in `scripts/` calls `send_email`.

## What changed

Both mock branches now log only a short warning and return `False`:

```python
                logger.warning("Email provider is not configured; no email was sent.")
                return False
```

The warning contains no recipient address, subject, or body. The SMTP and Resend delivery branches are unchanged.

## Test

`tests/test_emailer_safe.py` parametrizes the `resend` and `smtp` mock branches, clears the relevant credentials, and calls `send_email` with the body `"TEST-BODY-123"`. It asserts that the return value is `False` and that the body text appears in neither captured stdout nor stderr. No network or database calls are made.
