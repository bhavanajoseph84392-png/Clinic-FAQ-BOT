# Clinic FAQ Bot: Build Spec

## 14-Day Roadmap
- Day 1: Repo, README plan, Postgres with pgvector, FastAPI hello, deploy setup.
- Day 2: Database migrations, clinic signup, login, logout.
- Day 3: Row-level security (RLS) and tenant middleware/isolation.
- Day 4: Knowledge base text CRUD and dashboard.
- Day 5: PDF/price-list upload, chunking, embeddings, hybrid search.
- Day 6: Answer pipeline, thresholds, grounding check.
- Day 7: Patient chat page, session, fallback message.
- Day 8: Pending queue, admin reply, email to patient, Add to knowledge.
- Day 9: Ratings, lessons, lesson-first retrieval.
- Day 10: Ask Again side-by-side, lesson toggle and delete.
- Day 11: Analytics page, dashboard counts, demo seed data.
- Day 12: API keys, /ask, /questions, rate limit, webhook, Swagger.
- Day 13: Security pass, full test run, bug fixes, live deploy check.
- Day 14: Demonstration and final submission.
